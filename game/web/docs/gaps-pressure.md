# Pressure-pumping equipment gaps: sourced dimensions

Rule: every number below is cited. If no primary source gave a number, it is marked "not found". This was a short search pass, so many items are still open.

## 1. Zipper manifold (frac zipper)
- Overall size, skid size, height, valves per leg: **not found**.
- FET DuraLine (large-bore manifold system): FET's comparison lists the large-bore connection as a **7" DuraLock hub with 4 bolts**, against a **7-1/16" API flange with 16 bolts** on its older HydraLine system. Its brochure describes each skid as having **four ports**, with skids added to size the manifold. https://f-e-t.com/stimulation/duraline-manifold (the brochure PDF https://f-e-t.com/wp-content/uploads/2024/04/DuraLine-Manifold_2024.pdf now returns 404).
- Large-bore connection to the tree: a flexible frac hose with 7-1/16" 15K API 6A flanges, in **5" and 6" ID x 20 ft** sizes (Austin Hose drawings):
  - https://austinhose.com/customer/docs/skudocs/power-frac-pa-5-15k-7-1-16-fxflt-20ft-crimped-top-view-3.pdf
  - https://austinhose.com/customer/docs/skudocs/power-frac-pa-6-15k-7-1-16-fxflt-20ft-crimped-top-view-3.pdf
- Sub-parts named in patents: spools, tees, crosses, gate valves, outlet heads. https://patents.google.com/patent/US10570692 (zipper bridge), https://patents.google.com/patent/US10955862 (mobile zipper unit). Patent figures are useful as layout references.
- Paint colour: not checked.

## 2. Frac tree, 7-1/16" 15K
- **7-1/16" 15K Type 6BX flange**
  - OD: **505 mm** (about 19-7/8"). Bolting: **16 holes, each 42 mm**. Ring: **BX-156**. https://www.ikm.com/ikm-testing-norway/equipment-catalog/api/bfa07011615k-001
  - Bolt circle and flange thickness: **not found** in a source I could read. One table gives BC 15.88" and thickness 4.06", but its OD (18.88") matches the 10K flange, so I did not use it.
- **BX-156 ring** (TME data sheet, inches): OD **9.367**, height H **0.733**, width A **0.733**, ODT **9.263**, C **0.629**, D **0.12**, E **0.44**, G **9.521**, N **0.921**, weight **4.14 lb**. https://cdn.shopify.com/s/files/1/0881/7528/files/TME_BX.pdf
- **Gate valve face-to-face lengths**
  - 5-1/8" 15K: 737 mm (about 29.0") and 7-1/16" 15K: 889 mm (about 35.0"). Both come from a Scribd copy of a manufacturer sheet whose columns are not labelled, so treat them as **unconfirmed**. https://www.scribd.com/document/259700254/5-API-6A
  - Confirmed face-to-face values: **not found**.
- Hydraulic actuator size, overall stack height, goat head inlet count and size: **not found**.
- Reference: https://f-e-t.com/wp-content/uploads/2024/08/API-6A-Gate-Valve-Flyer.pdf (gate valve flyer, not opened).

## 4. High-pressure treating iron
- **Cameron (SLB) flow iron pup joints**, all rated **15,000 psi**, with 1502 hammer unions and NPST threads. https://www.slb.com/-/media/files/sur/product-sheet/flow-iron-pups-ps.ashx
  - 2" size: bore **1.72"**, lengths **4, 6, 8 and 10 ft**.
  - 3" size: bore **2.59"**, lengths **2, 3, 4 and 8 ft**.
  - Both sizes come in nondetachable and detachable-nut versions.
  - Range given in the sheet text: 2 to 10 ft.
- Pup OD and union nut OD: **not found**.
- Chiksan swivels (Style 10/50/80), plug valves, check valves, 1502 wing nut dimensions: **not found**.
- Leads not opened: AbDex hammer union table (it covers elbows, tees and wyes) https://www.scribd.com/document/700823827/AbDex-Hammer-Unions, and the SPM flow catalogue https://www.scribd.com/document/605878675/SPM-Flow-Catalogue
